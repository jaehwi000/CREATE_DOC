# CREATE_DOC — 행정문서 작성 도우미 (POC)

대학별 양식 예시를 한 번 분석해 두고, 내용만 넣으면 그 양식대로 **출장복명서·지출결의서** 초안을 만드는 정적 웹 페이지입니다. 서버가 없어서 GitHub Pages에 그대로 올리면 됩니다.

## 흐름

| 단계 | 하는 일 |
|---|---|
| 1. 양식 예시 올리기 | 결재 완료된 같은 종류 문서 2~5건 (`.hwpx` `.docx` `.txt`, 또는 본문 붙여넣기) |
| 2. 양식 규칙 분석 | 제목, 대항목 순서, 번호 체계(1.→가.→1)), 개요 라벨, 문체(개조식/합니다체), 날짜·요일·금액 표기, "끝." 여부를 추출해 **양식 프로필**로 저장. 직접 수정 가능, JSON으로 내보내기/가져오기 |
| 3. 내용 입력 | 확정 사실은 입력칸(지출내역은 산출근거 `47,600원 × 2명` 입력 시 금액 자동 계산), 정리 안 된 메모는 참고자료란 |
| 4. 생성·점검 | ① 프롬프트 복사 → 쓰던 AI에 붙여넣고 결과를 다시 붙여넣기 (키 불필요) ② Claude API 직접 호출. 결과는 자동 점검 |

**자동 점검 항목**: 날짜–요일 불일치, 총액·항목 금액 누락, 한글 금액(금일백…원) 불일치, `A × B = C` 계산 오류, 개조식 문체 이탈, "끝." 누락, 마크다운 기호, `[확인 필요]` 표시, 입력·자료에 없는 숫자.

## GitHub Pages 배포

```bash
git init && git add . && git commit -m "POC"
git branch -M main
git remote add origin https://github.com/<계정>/<저장소>.git
git push -u origin main
```
저장소 **Settings → Pages → Branch: main / (root)** 선택 후 저장하면 `https://<계정>.github.io/<저장소>/`에서 열립니다.

로컬 확인: `python3 -m http.server` 후 `http://localhost:8000`.

## 파일 구성

```
index.html          화면
assets/core.js      양식 분석 · 프롬프트 조립 · 결과 점검 (Node에서도 require 가능)
assets/app.js       화면 동작, 파일 파싱(HWPX/DOCX), API 호출
assets/style.css
assets/samples.js   가상 예시 데이터 (samples/*.txt 내용)
samples/            가상 양식 예시와 메모 (실제 대학 문서 아님)
```

## 데이터·보안

- 입력값과 프로필은 브라우저 localStorage에만 저장됩니다.
- API 모드에서는 문서 내용이 사용자 키로 Anthropic API에 직접 전송됩니다(브라우저 직접 호출 헤더 사용). 키는 기본 세션 저장, 체크 시 localStorage 저장.
- 실제 학교 문서를 예시로 쓸 때는 인명·계좌 등 개인정보를 지우세요. 공개 저장소에 실제 문서를 커밋하지 마세요.

## POC 한계와 다음 단계

- `.hwp`(바이너리), PDF 미지원 → 한글에서 HWPX로 저장하거나 본문 붙여넣기
- 출력은 텍스트(그룹웨어 본문 붙여넣기용). 다음 단계: HWPX 양식 파일의 누름틀/표 칸에 직접 채워 넣기
- 규칙 분석은 정규식 기반이라 양식이 특이하면 프로필을 손으로 고쳐야 함. "AI로 문체 특징 보완"으로 보조
- 판매형으로 가려면 API 키를 사용자에게 받지 않도록 서버(프록시) 또는 설치형 구성이 필요
